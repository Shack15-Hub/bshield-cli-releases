# bshield CLI releases

Signed release assets for the bshield terminal client on macOS and Linux.

Install the beta with:

```sh
curl -fsSL https://github.com/Shack15-Hub/bshield-cli-releases/releases/download/beta-channel/install.sh | sh
```

The installer verifies the signed release manifest and both executables. Source development is in Shack15-Hub/bshield-cli.
